# Copper Isles — Game One Lore

> **Scope.** This directory holds the lore that drives Game One, which now takes place entirely within the Copper Isles archipelago. Roland is the only protagonist whose arc is currently planned in detail. Other companions, the Sundered Crown plotline, and the broader Mira-Thal trilogy material remain valid universe lore but are not in scope for Game One as currently being built.
>
> **Relationship to the rest of `/lore`.** Everything outside this directory is universe lore — the wider world Game One inherits but doesn't directly play in. `lore/WORLD.md`, `lore/PEOPLES.md`, `lore/HISTORY_*.md`, `lore/locations/*.md` (Solgrade, Caer Brannoch, Aelorin, etc.) all describe the world Roland comes from. The Copper Isles are part of that world; Solgrade's Merchant's Council is the political force that has chartered the colonial extraction operation here.
