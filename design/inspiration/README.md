# design/inspiration/

Permanent visual direction folder for the 10cm-voxel re-architecture (PR track R0–R4).

Claude Fable — the project's primary game coder — refers back to these images when making implementation decisions about terrain resolution, flora density, lighting quality, and view distance. If you're about to write code that touches any of those systems, open this folder first.
